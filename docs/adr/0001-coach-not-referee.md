# The app coaches; it does not referee

Cindy counts what the athlete does and attaches rep quality to each banked rep (depth, lockout, tempo, asymmetry), but quality never removes a rep from the score. We decided this on 2026-10-19 against a proposal to "count only valid reps", because the app is a local logbook with nothing to win by cheating, because it already accepts adapted variations on purpose (a knee push-up counts as a push-up rather than locking people out), and because a pose-only camera cannot verify standards such as assistance, so an automatic no rep would be false certainty. The few movement gates that exist today (head over the bar, a return to a dead hang) stay as they are; attempts they refuse are recorded as unbanked attempts instead of vanishing. No reps belong to an opt-in Judge mode, which is not built.

## Considered Options

- Count only reps that pass quality criteria (the proposal): rejected for the reasons above.
- Coach by default, Judge mode as an option: the chosen direction, with Judge mode deferred.
