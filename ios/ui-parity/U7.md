# U7: Retire the Old Styling Implementation Plan

**Goal:** the iPhone app no longer defines the colours, chip and buttons it wore before the Android-shaped screens, and `ios/PARITY.md` and `ios/README.md` describe what is there.

**Architecture:** deletions only. Every screen already draws from `Palette`, `CindyType`, `CindyViews` and `CindySheet`; this phase removes what nothing reads.

**Spec:** `ios/ui-parity/PLAN.md` (U7) and `docs/adr/0003-ios-follows-android-ui.md`.

## What stays out of this phase

- **Component files are not folded into `CindyViews.swift`.** The plan reserved that file for U0 and U7 so parallel phases would not collide. The phases added `CindySheet.swift`, `SheetKit.swift`, `ProgressCards.swift`, `PopGesture.swift` and `AvatarView.swift`, each one thing and 100 to 360 lines. Folding them would make a 1,000-line file for no reader's gain, so they stay.

## Two stages

U6 (#100) is not on `main`, and `PlacementGuideView.swift` is the last user of `Color.dim`, `Color.warn` and `PrimaryButton`. U6 rewrites that file.

1. **Now.** Delete what nothing reads: `Ink`, `GhostButton`, `Chip` and `.chip()`. The debug readout takes `Palette.labelSecondary` and its capsule inline.
2. **After #100 is on `main`.** Delete `Color.accent`, `Color.dim`, `Color.warn`, `Color.appBackground` and `PrimaryButton`; the camera screen's background becomes `Palette.background`. The grep below must find nothing.
